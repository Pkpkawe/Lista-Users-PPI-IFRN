# 👥 Lista de Usuários

Projeto desenvolvido como atividade prática de **React + Vite**, com o objetivo de trabalhar **componentes, props e consumo de API**.

A aplicação busca usuários da API [DummyJSON](https://dummyjson.com/users) e exibe suas informações em cartões individuais.

## 🚀 Tecnologias utilizadas

- React
- JavaScript
- Vite
- TailwindCSS
- DummyJSON API

## 🌐 API utilizada

Os dados dos usuários são obtidos através da API:

https://dummyjson.com/users

A API fornece informações como:

- Nome;
- Idade;
- Gênero;
- E-mail;
- Telefone;
- Imagem;
- Empresa;
- Cargo;
- Cidade e estado.
